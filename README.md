# A Little Apology ♡

A simple, three-page apology website made with plain HTML and CSS. No paid tools or packages are needed.

## Open it in Visual Studio Code
1. Extract this ZIP file.
2. In VS Code, choose **File → Open Folder…** and select `amira_apology_website`.
3. Open `index.html` in your browser. For a smoother workflow, install the **Live Server** extension in VS Code, right-click `index.html`, then choose **Open with Live Server**.

## Publish it free with GitHub Pages
1. Create a new repository on GitHub (for example, `for-amira`). You can make it public for the easiest GitHub Pages setup.
2. Upload the files and folders from this project to the repository's root. Keep `images/our-photo.png` inside the `images` folder.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Personalise it
- Edit the words in `index.html`, `invitation.html`, and `please.html`.
- Replace `images/our-photo.png` with another photo, keeping the same filename.
- The website works without JavaScript; `script.js` is optional.

A gentle reminder: a website can open a door, but give her room to decide whether and when she wants to talk. The most meaningful apology is the change you show consistently.
